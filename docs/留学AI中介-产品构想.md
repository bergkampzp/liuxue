# 留学 AI 中介 — 产品构想

> 面向国际学校场景 | 版本 V1.0 | 2026-06-10
> 探讨：AI 能否部分替代传统留学中介的知识服务？

---

## 一、传统留学中介在做什么

### 1.1 完整服务链条

从签约到出国，传统中介的服务覆盖以下节点：

```
签约 → 选校定位 → 背景提升 → 文书创作 → 申请提交 → 面试辅导 → 
签证办理 → 行前指导 → 出境衔接（住宿/接机）
```

| 环节 | 具体内容 | 中介核心能力 | AI 可替代性 |
|:---|:---|:---|:---:|
| **选校定位** | 根据 GPA/语言/活动/预算匹配学校，分冲刺/匹配/保底三档 | 经验数据库 + 往年案例 + 学校关系 | ⭐⭐⭐⭐⭐ 高 |
| **背景提升** | 规划竞赛/实习/科研/夏校 | 对学校偏好的理解 | ⭐⭐⭐ 中 |
| **文书创作** | PS/SOP/推荐信/简历的撰写和修改 | 写作能力 + 对学校偏好的理解 | ⭐⭐⭐⭐ 较高 |
| **申请提交** | 填网申系统、跟踪截止日、管理材料 | 流程管理和细节把控 | ⭐⭐⭐⭐⭐ 高 |
| **面试辅导** | 模拟面试、题库训练 | 经验积累 | ⭐⭐⭐ 中 |
| **签证办理** | 材料准备、面签辅导 | 政策熟悉 | ⭐⭐⭐ 中 |
| **行前指导** | 住宿、机票、汇款、选课 | 信息汇总 | ⭐⭐⭐⭐ 较高 |

**收费**：全套服务 3-15 万人民币（按国家/学校难度分层），单项 5,000-20,000 元。

### 1.2 中介的核心资产

| 资产 | 说明 | 是否可被 AI 替代 |
|:---|:---|:---:|
| **信息优势** | 知道各学校真实录取门槛、偏好、录取率 | ✅ 可被数据爬取 + LLM 汇总替代 |
| **经验数据库** | "GPA 3.5 + 托福 105 能申到哪些学校" | ✅ 这就是结构化数据 + RAG |
| **人脉** | 与学校招生办的关系 | ⚠️ 部分可被替代，部分不可 |
| **写作能力** | 写出打动招生官的文书 | ✅ LLM 核心能力 |
| **流程管理** | 不错过截止日、提交正确的材料 | ✅ 程序化任务 |

## 二、现有的 AI 留学产品

### 2.1 国际产品

| 产品 | 定位 | 核心功能 | 对我国的启示 |
|:---|:---|:---|:---|
| **ApplyBoard** | 留学申请平台 | 150,000+ 项目、AI 引导搜索、95% 申请成功率 | 多国多项目聚合 + AI 匹配 |
| **GradCafe** | 录取数据众包 | 840K+ 录取案例、250+ 学校、按专业搜索 | 公开录取数据的最大价值 |
| **CollegeVine** | B2B 大学 AI 平台 | AI 运营系统、招生管理、学生事务 | 偏 B2B，非学生端 |

### 2.2 国内产品

| 产品 | 特点 | 与 AI 的结合 |
|:---|:---|:---|
| **新东方前途出国** | 行业最大，全套服务 5-15 万 | 官网有"智能选校"模块但深度有限 |
| **再来人** | 高端申请，侧重文书和背景提升 | 使用 AI 做选校匹配 |
| **棕榈大道** | 导师制，Mentor 模式 | 数据驱动选校 |
| **"张雪峰报考助手"** | 高考志愿数字人 | 知识库 + 问答，模式值得借鉴 |

### 2.3 竞品启示

现有产品做得好的：
- 选校匹配（ApplyBoard、再来人）
- 录取数据众包（GradCafe）

现有产品做得不好的：
- **没有完整的 AI 端到端覆盖**（选校 + 文书 + 申请 + 签证）
- **没有对中国国际学校场景的适配**（IB/AP/A-Level 成绩换算、英/美/加/澳多国混申）
- **文书 AI 辅助停留在"模板填空"**，没做到个性化

## 三、留学 AI 需要哪些数据

### 3.1 从网络可获取的数据（公开/半公开）

| 数据类别 | 具体来源 | 获取方式 | 质量 |
|:---|:---|:---|:---:|
| **排名数据** | QS / THE / US News / 软科 | 爬虫 + API（部分付费） | 高 |
| **录取案例** | GradCafe（840K+ 条）、一亩三分地、寄托天下、Reddit r/gradadmissions | 爬虫 | 中高（众包但有偏） |
| **学校录取要求** | 各大学官网 Admissions 页面 | 爬虫 + LLM 结构化提取 | 高 |
| **专业信息** | 大学官网 Program 页面、课程设置、学费 | 爬虫 + LLM 提取 | 高 |
| **签证政策** | 各国移民局官网 | 定期爬取 + 结构化 | 高 |
| **申请文书范例** | 各留学论坛分享、GitHub 上的 SOP 模板 | 爬虫 | 中（质量参差） |
| **标准化考试数据** | College Board, ACT, ETS, IELTS 官网 | 爬虫 | 高 |
| **就业数据** | LinkedIn, Glassdoor, 各大学 Career Report | 部分爬取 + PDF 解析 | 中 |

### 3.2 网络找不到的（需要行业经验）

| 数据类别 | 为什么网上没有 | 如何获取 |
|:---|:---|:---|
| **"潜规则"录取偏好** | 学校不会公开写"我们喜欢有 X 背景的学生" | 从业 5 年+的中介顾问口述 → 录入知识库 |
| **真实成功案例细节** | 中介的案例库是商业机密 | 从做中介的朋友获取脱敏后的案例数据 |
| **文书"套路"** | 好的中介有自己打磨的框架 | 访谈资深文书顾问 |
| **申请时间线的"暗坑"** | 提前批 vs 常规批，滚动录取的实际节奏 | 中介经验 |
| **签证面签的"避坑指南"** | 签证官问什么、怎么回答 | 中介积累的面签题库 |

### 3.3 建议向做中介的朋友要的数据

| 数据 | 用途 | 数据格式 |
|:---|:---|:---|
| 脱敏后的录取案例（50-200 条） | 训练选校匹配模型 | Excel: GPA, 语言成绩, 学校, 专业, 录取结果 |
| 文书框架和范例（10-20 篇） | 训练文书生成模型 | 文本: PS/SOP 各国家各专业 |
| 申请时间线模板 | 系统自动规划 | Excel: 各学校各轮的截止日期 |
| 面签题库（50-100 题） | 模拟面试 | Q&A 格式 |
| 常见 Q&A（200+ 条） | 知识库问答 | Q&A 格式 |

## 四、留学 AI 的能力模型

### 4.1 七项核心能力

```
┌─────────────────────────────────────────────────────────┐
│                  留学 AI 中介能力模型                      │
│                                                          │
│  ① 智能选校引擎                                          │
│     输入: GPA + 语言 + 预算 + 方向 → 输出: 冲/匹/保 三档  │
│     数据源: GradCafe + 中介案例库 + 大学录取要求           │
│                                                          │
│  ② 文书智能助手                                          │
│     输入: 学生经历 + 目标学校 → 输出: 个性化 PS/SOP 草稿  │
│     数据源: 范例文库 + 中介框架 + LLM 写作能力             │
│                                                          │
│  ③ 申请时间线管理                                        │
│     输入: 目标学校列表 → 输出: 个性化申请日历 + 提醒       │
│     数据源: 大学官网截日 + 中介经验                        │
│                                                          │
│  ④ 面签/面试模拟                                         │
│     输入: 学校/签证类型 → 输出: 模拟对话 + 反馈            │
│     数据源: 面签题库 + 面试真题                            │
│                                                          │
│  ⑤ 知识库问答                                            │
│     输入: 任意留学问题 → 输出: 准确答案                    │
│     数据源: 中介 Q&A + 大学官网 + 签证政策                 │
│                                                          │
│  ⑥ 申请材料审核                                           │
│     输入: 学生上传的材料 → 输出: 完整性检查 + 建议          │
│     数据源: 各校 checklist                                 │
│                                                          │
│  ⑦ 费用估算与规划                                         │
│     输入: 目标学校/城市 → 输出: 学费 + 生活费 + 总预算      │
│     数据源: 大学官网 + 城市生活成本数据                     │
└─────────────────────────────────────────────────────────┘
```

### 4.2 选校引擎 — 核心差异化能力

这是整个留学 AI 最有价值的部分。实现方式：

```
学生输入:
  GPA: 3.6/4.0
  托福: 105
  IB 预估分: 38/45
  专业方向: Computer Science
  国家偏好: 美/英/加
  预算: 50 万/年

AI 处理流程:
  ① 从 GradCafe + 中介案例库中检索相似 profile
     "GPA 3.5-3.7 + 托福 100-108 + CS + 各校录取率"

  ② 从大学官网提取录取要求
     "UC Berkeley EECS: 建议 GPA 3.7+"
     "University of Toronto CS: 建议 IB 36+"

  ③ LLM 综合判断 → 三档推荐
     冲刺: UC Berkeley, CMU, Imperial
     匹配: UIUC, U of Toronto, UBC
     保底: UC Davis, Waterloo, Manchester

  ④ 每所学校附带:
     - 该 profile 的历史录取率
     - 该专业的排名和特色
     - 语言成绩是否需要再刷
     - GPA 是否在安全区间
     - 申请截止日期
```

## 五、构建路径

### 5.1 三阶段计划

| 阶段 | 时间 | 目标 | 核心动作 |
|:---|:---|:---|:---|
| **Phase 1: 数据筑基** | 2-3 周 | 建立数据池 | ①爬取 GradCafe/大学官网/排名数据 ②访谈到 2-3 位中介朋友录入经验 ③构建结构化数据库 |
| **Phase 2: MVP** | 2-3 周 | 三大核心功能上线 | ①智能选校引擎 ②知识库问答 ③申请时间线管理 |
| **Phase 3: 增强** | 持续 | 补齐六项能力 | ①文书助手 ②面签模拟 ③材料审核 ④费用估算 |

### 5.2 Phase 1 具体动作

**数据爬取（自动化）**：
| 任务 | 工具 | 产出 |
|:---|:---|:---|
| GradCafe 录取数据爬取 | Python + Scrapy | 目标专业 500+ 条录取记录 |
| 排名数据 | QS/THE 官网爬取 + 公开 CSV | Top 200 大学排名表 |
| 大学官网录取要求 | 爬虫 + LLM 结构化提取 | 50 所目标院校的录取条件 |

**经验录入（人工 + LLM 辅助）**：
| 任务 | 方式 | 产出 |
|:---|:---|:---|
| 中介顾问访谈 | 录音 → LLM 转结构化知识点 | 选校经验 50+ 条、文书框架 10 篇 |
| 面签题库整理 | 中介提供 + 论坛收集 | Q&A 100 对 |
| 申请时间线梳理 | 中介提供各校各轮截日 | Excel 导入 |

### 5.3 为什么值得做

| 维度 | 数据 |
|:---|:---|
| **市场** | 中国每年出国留学生 70 万+，中介市场规模 200 亿+ |
| **成本** | AI 单次服务成本几分钱到几毛钱 vs 人工中介 3-15 万 |
| **差异化** | 目前没有完整覆盖选校+文书+申请+签证全流程的 AI 产品 |
| **切入点** | 从国际学校场景切入（IB/AP 学生有明确需求），逐步扩展 |

## 六、与学校教师评价系统的协同

这个留学 AI 可以复用学校已有的数据资产：

| 学校已有数据 | 留学 AI 如何使用 |
|:---|:---|
| 学生成绩（LMS） | 自动提取 GPA，省去学生手动输入 |
| 标准化考试成绩 | IB/AP/A-Level 成绩换算为各国标准 |
| 学生活动/竞赛记录 | 自动填充简历/活动列表 |
| 教师评价记录 | 推荐信用素材 + 选校参考 |
| 学校历史录取数据 | 最重要的选校参考数据 |

**形成闭环**：教师评价系统提供学生画像 → 留学 AI 提供个性化升学建议 → 评价系统追踪毕业生去向 → 反哺选校模型。
