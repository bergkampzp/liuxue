## 一、产品经理视角

### 1.1 用户角色分析

| 角色 | 核心诉求（看什么） | 核心动作（做什么） |
|:---|:---|:---|
| **校长** | 全校教师发展全景图、高风险/高潜力教师识别、学校整体教学质量趋势、学科学部均衡度 | 审批评价周期、查看风险预警、制定师资调配与培训预算 |
| **教研组长** | 本组组员能力雷达对比、薄弱维度分布、集体备课参与度、听课互评排名 | 发起同行互评、审核 AI 生成的评语初稿、组织教研活动 |
| **教师本人** | 个人综合评分+雷达图（各维度历史对比）、AI 生成的"教学改进建议"、学生/家长满意度反馈详情 | 查看反馈、上传补充材料、设置个人发展目标 |
| **家长** | 孩子任课教师的整体评价概览（等级制）、家校沟通频次与质量评分 | 填写学期末满意度问卷 |
| **学生** | 对每堂课的即时微反馈 | 在课中/课后完成 AI 推送的 1 分钟微反馈 |

### 1.2 评价维度设计（"4+1"框架）

采用国际通行的评价框架（Danielson Framework + Marzano Model），结合中国国际学校场景定制：

#### 维度一：教学能力（权重 30%）

| 子维度 | 数据来源 | AI 分析方式 |
|--------|----------|------------|
| 课堂设计 | 教案/课件 | AI 分析教学目标清晰度、差异化教学设计 |
| 教学实施 | 课堂录音 | 师生话轮比、Bloom 提问层次分布、等待时间 |
| 学生参与度 | 课堂视频 | 抬头率、举手频次、小组讨论活跃度 |

#### 维度二：学生发展（权重 25%）

| 子维度 | 数据来源 | AI 分析方式 |
|--------|----------|------------|
| 成绩增长 | 校内/标准化考试 | Student Growth Percentile 增值模型 |
| 个性发展 | 竞赛/社团 | AI 提取教师辅导成果、个性化评语质量分析 |
| 选课辅导 | 升学记录 | 对 IB/AP/A-Level 选课指导的准确性评估 |

#### 维度三：专业素养（权重 20%）

| 子维度 | 数据来源 | AI 分析方式 |
|--------|----------|------------|
| 教研参与 | 教研系统 | 集体备课签到、公开课次数、学术会议 |
| 持续发展 | 培训系统 | 培训学分、阅读分享频次 |
| 创新尝试 | 教师自述 | AI 验证教学创新与教学改进的关系 |

#### 维度四：家校沟通（权重 15%）

| 子维度 | 数据来源 | AI 分析方式 |
|--------|----------|------------|
| 家长满意度 | 问卷 | 学期末家长问卷评分 |
| 沟通质量 | 沟通记录 | AI 分析沟通频次、负面情绪词比例、响应时效 |

#### 维度五：同行评价（权重 10%）

| 子维度 | 数据来源 | AI 分析方式 |
|--------|----------|------------|
| 互评 | 听课反馈卡 | AI 校正：异常高分/低分自动提醒组长介入 |
| 教研组评价 | 组长评分 | 组内相对排名和趋势分析 |

### 1.3 产品功能模块

| 模块 | 核心能力 | AI 介入程度 |
|:---|:---|:---:|
| **评价配置中心** | 设定维度权重、评价周期模板、定义数据源接入规则 | 低 |
| **AI 分析引擎** | 课堂实录分析、文本情感分析、增值模型计算 | 高 |
| **教师发展看板** | 多维雷达图（历史对比）、AI 改进建议、个性化培训推荐 | 中 |
| **管理层指挥舱** | 全校教师热力图、高潜力教师发现、异常预警 | 高 |
| **360 反馈台** | 学生微反馈、家长满意度、同行互评随机匹配 | 中 |
| **报告与导出** | 中英文教师发展报告、PDF 导出、校董会汇报图表 | 低 |

### 1.4 评价周期

| 阶段 | 时间 | 内容 | AI 角色 |
|:---|:---|:---|:---|
| 过程性评价（70%） | 第 1-18 周 | 每周自动抓取数据、每天学生微反馈、每月同行互评 | 持续记录、异常报警 |
| 中期回顾 | 第 9 周 | 教师收到半期雷达图、与组长进行发展对话 | 生成对比图、推荐议题 |
| 终结性评价（30%） | 第 18-20 周 | 校长/组长最终等级评定（A/B/C/D） | 自动汇总、生成摘要 |
| 改进计划 | 假期 | AI 推荐下学年发展目标 | 个性化 PDP 草稿 |

### 1.5 关键看板设计

**校长总览看板**：
- 顶部：全校总评分分布直方图（绿/黄/红区）
- 中部：四维度学科平均分对比折线图
- 右侧：AI 推荐"高潜力教师"Top 5 + "需关注教师"Top 5
- 底部：教师排名前 20% 列表

**教师个人发展报告**：
- 首页：五维雷达图（本学期/上学期/组内平均三条线对比）
- 第二屏：AI 洞察 — "优点" + "改进点"（数据驱动）
- 第三屏：家长沟通时间线 + 情绪分析曲线
- 第四屏：同行反馈匿名评分分布 + 评语关键词云

## 二、项目经理视角

### 2.1 分阶段交付计划

| 阶段 | 名称 | 目标 | 范围 | 预估工时 |
|:---|:---|:---|:---|:---:|

| **Phase 2** | 增强 | 增加教师自评/互评、家长端反馈、更多 AI 维度 | 教师个人报告、自评/互评、家长问卷系统、情绪识别、教学设计链检测 | 180 人·天 |

### 3.2 课堂语音分析流水线

```
原始音频 → VAD(语音活动检测) → 说话人分离 → ASR → 时序文本
                                                         │
                    ┌────────────────────────────────────┤
                    ▼                                    ▼
              Bloom提问分类器                     教师话语分析器
              (6层次:记忆→创造)                   (IRF分析/提问率/
                    │                            等待时间/TTT)
                    ▼                                    ▼
              语速/情感分析 → 结构化输出 JSON
```

**输出示例**：
```json
{
  "teacher_talk_ratio": 0.52,
  "bloom_distribution": {"remember": 0.18, "understand": 0.31, 
                         "apply": 0.27, "analyze": 0.14, 
                         "evaluate": 0.07, "create": 0.03},
  "question_rate": 0.23,
  "avg_wait_time": 2.7,
  "speech_rate_wpm": 145,
  "emotional_timeline": [...]
}
```

```
                                                  │
                    ┌─────────────────────────────┤
                    ▼                             ▼

                     ▼                             ▼

             → 融合输出 JSON
```

### 3.4 模型选型建议

#### 语音识别

| 方案 | 中文精度 | 延迟 | 隐私 | 成本 |
|:---|:-------:|:---:|:---:|:---:|
| Whisper large-v3（本地） | ~85% | 音频×0.5-1 | ✅完全本地 | GPU 成本 |
| 火山引擎 ASR（云端） | ~95% | <300ms | ⚠️数据传输 | 按小时计 |

**推荐**：日常课堂混合模式（本地初步识别+云端纠错），涉密课程纯本地

#### 语义分析

| 任务 | 推荐 | 方式 |
|:---|:---|:---|
| Bloom 分类 | DeepSeek 7B（LoRA 微调） | 边缘推理 |
| 情感分析 | DeepSeek 7B（prompt） | API 调用 |
| 报告生成 | DeepSeek 67B / GPT-4o | 云端 API |
| 关键词抽取 | BERT-base（fine-tuned） | 边缘推理 |

**分层策略**：高频低延迟→传统 ML + 小模型；复杂语义→大模型 API；
隐私敏感→本地 7B 模型（ollama/vLLM）

#### 视频行为分析

| 任务 | 推荐模型 | 推理速度(T4) |
|:---|:---|:---:|
| 人体检测 | YOLOv8n (3.2M) | 2ms |
| 人脸检测 | RetinaFace (1.0M) | 5ms |
| 姿态估计 | RTMPose-s (5.5M) | 3ms |
| 动作识别 | TSM-ResNet18 (10.5M) | 8ms |

### 3.5 评价引擎设计

**加权聚合公式**：
```
总分 = Σ( w_j * Σ( w_ij * x_ij ) )

示例——教学质量 = 0.35×Bloom广度 + 0.25×提问频率 + 0.20×教师话语比(逆) + 0.20×等待时间
```

**归一化策略**：
- 有明确上下界的指标 → Min-Max 极值归一化
- 正态分布假设的指标 → Z-score 标准化
- SGP 等排位指标 → 百分位不变
- 定性指标 → 离散映射 5 档

**AI 评语生成**（结构化模板+大模型+后处理校验）：
```
[教师姓名]在[科目]教学中展现出[总体评价]：
1. 教学创新：[Bloom层次分析] + [建议]
2. 课堂互动：[参与度指标] + [解读]
3. 学生发展：[SGP变化] + [趋势分析]
4. 沟通质量：[家长沟通指标] + [评语分析]
5. 待改进项：[弱项] + [专项建议]
```

### 3.6 数据安全方案

**视频脱敏分级**：

| 级别 | 处理 | 适用场景 |
|:---|:---|:---|
| L1 | 人脸模糊+学生名隐去 | 教研分析（默认） |
| L2 | 人脸模糊但可辨师生 | 教学评估（需审批） |
| L3 | 原始（权限控制） | 合规监控 |
| L4 | 仅统计值 | 公开报告 |

**边缘计算策略**：所有可识别身份的原始数据（人脸、语音波形）只在边缘节点停留，云端只接收脱敏后的结构化指标。

**合规**：符合《个人信息保护法》《数据安全法》《未成年人保护法》《等保 2.0》三级要求。教师离职后 30 天内全部数据删除。

### 给客户的沟通要点

1. **这是一个"赋能型"而非"监控型"工具**
   - AI 只做数据分析和趋势发现，不做人事决策
   - 最终等级由教研组长+校长双人确认
   - 数据安全：原始视频不出校园，脱敏后在本地处理

2. **数据是核心资产**
   - 建议先做 2 个学期的 baseline 数据对齐
   - 学校已有的 SaaS/LMS/录播数据就是金矿
   - 即使数据有"泥"（不规整），AI 也能洗干净分析

3. **投入产出预期**
   - Phase 1 投入约 120 人·天（3 个月）即可上线核心能力
   - 教师评价从"凭感觉"到"凭数据"，大幅提升管理精度
