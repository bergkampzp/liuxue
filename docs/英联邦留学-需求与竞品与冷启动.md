> 方法：现有代码资产盘点 + 一轮对抗验证的市场调研（22 来源 / 68 主张 / 17 核实 / 8 驳回）+ 两路深入研究（竞品、冷启动数据）

## 〇、为什么聚焦英联邦：与美研的本质差异

现有系统（GradCafe + 一亩三分地 + 寄托 → dbt 四层 → BI 看板）是**美研导向**的：录取概率 = f(GPA 分位数, GRE 区分度, 录取率)。但英联邦（尤其英国硕士）的录取逻辑根本不同：

> **录取 ≈ f(中国本科院校档位 × 均分 × 专业对口 × 雅思小分)，且院校档位可盖过裸均分。**

经对抗验证（3-0 通过）的事实：
- **英国名校按中国本科院校档位设差异化均分线**：UCL list 内 85 / list 外 90；牛津 985/211 vs 其他两档线；曼大认可名单卡到 ~82；爱丁堡 A/B/C/D 四档 Priority List。
- **GRE 对英联邦硕士基本无用**——现有 `feat_gre_impact` 对英联邦失效。
- **con offer（有条件录取）→ uncon 转化是真实机制**，是持续焦虑点。

被驳回的"伪常识"（避免写进产品逻辑）：
- ❌ "第一轮 9-10 月投递录取率更高 / 学校越往后越严"（0-3 驳回）。rolling 真相是**名额先到先得、晚投档位掉甚至关闭**，但不是学校主动抬标准。
- ❌ "11 所 THE Top100 都维护 list 且是门槛性筛选"、"剑桥三级 85/88/90 具体数字"（0-3 驳回）。**list 与均分线高度时效、按校而异，不能 hardcode，必须做成带来源+时效的数据资产。**
- ❌ 中介收费"8000-15000"具体数字（单一来源未核实，不作依据）。

## 一、客户核心需求（按"最焦虑 / 最愿付费"排序）

| # | 核心需求 | 用户焦虑 | 证据强度 |
|:--|:--|:--|:--|
| **1** | **选校定位 + 中国院校 list 匹配** | "我双非/82 分能申到哪一档？" | ✅ 核实(3-0)，**最愿付费=签约决策点** |
| **2** | **专业对口判断** | "本科非 CS 能转申 CS 硕士吗？" | ✅ 英澳硬卡课程匹配，不像美研可跨申 |
| **3** | **雅思规划（含小分卡线）** | "总分够但写作差 0.5 会被拒吗？" | ⚠️ 需求真实但**可靠数据稀缺**(open question) |
| **4** | **con offer 达成路径** | "有条件 offer 还差多少分换无条件？" | ✅ 核实(3-0) |
| **5** | **滚动录取节奏** | "现在投晚不晚、热门专业关没关？" | ✅ rolling 名额会满（但非"越晚越严"） |
| 6 | PS 个人陈述（英国一篇通用） | 写作焦虑 | 常识 |
| 7 | 签证（英 CAS / 澳 GTE-GS） | 临门一脚，澳 GS 拒签焦虑 | 常识 |

**结论：最愿付费 = 需求 1（选校定位 + 院校 list 匹配）**，这正是市场调研的核心结论——"核心痛点是中国院校认可名单带来的信息不对称，付费意愿最高、AI 数据空白最大"。

P0 = 需求 1-4（构成"能否签约"的核心）；P1 = 需求 5；P2 = 需求 6-7。

## 二、最直接竞品：指南者留学（Compass Education, compassedu.hk）

### 2.1 它是什么（已核实）
- **本质是重度传统中介，披工具外壳**：港/英全包服务费约 **1.8 万–2.4 万元**，"三对一"全职团队（咨询顾问+申请主导师+文书导师）。招聘信息暴露销售驱动本质（"公司每月提供 100+ 高意向客户、转介绍率 45%、销售导向岗位"）。
- **工具是获客漏斗，变现 100% 靠人工服务费**。

### 2.2 它的数据做法（已核实）
- **自有真实学生案例**约 2 万–3.7 万量级（口径不一，存夸大）。来源是**签约学生的真实申请结果沉淀**，形成"数据→案例→信任→签单→更多数据"飞轮——这是它最硬的护城河，爬取型竞品难复制。
- **"AI 极光选校"是统计匹配而非 LLM 推理**：输入背景 → 基于案例库 10 秒出冲/匹/保三档，自称 78% 准确率（无方法论披露）。App 仅 4.3 分/15 评，有卡顿吐槽，工具体验弱。
- **关键空白**：它有"按 985/211/双非分级"的录取战绩报告，**但均分线/list 锁在软文报告和顾问话术里，未做成结构化、可查询的数据库**。学校库（370 所）页面不显示录取分数门槛。

### 2.3 它的短板 = 我们的机会
| 短板 | 我们的切入 |
|:--|:--|
| 均分线未结构化（锁在报告/顾问嘴里） | **把"均分线/录取概率"结构化、可查询、可溯源**——直接打它信息不对称软肋 |
| 非真 AI（统计匹配+人工顾问） | 做真正的 **LLM 对话式选校规划**：可解释理由、动态追问、文书诊断 |
| 客群偏 985/211（案例里双非仅占 2%） | **主攻双非/普通本科 + 价格敏感 DIY 人群**——英联邦申请量最大的长尾 |
| 数据"可查"但外部不可验证 | 做 **"可验证"而非"trust me"**：来源标注 + 官方交叉验证 |
| 加拿大/爱尔兰是宣传性覆盖 | **补强港新 + 加拿大 + 爱尔兰**的结构化纵深 |
| 高客单价、非自助、重人工 | 用 AI 把人工成本压到接近零，**SaaS/订阅或 CPA 分润**变现，在它高人力结构下打价格战 |

> 注：98.2% 成功率、78% 准确率均为官方自报口径，无第三方审计，引用须标注"官方宣称"。

## 三、最核心数据资产的冷启动：院校 list × 均分录取线

这是需求 1 的命门，也是最难拿的数据（中介隐性知识、按校而异、逐年微调）。冷启动策略 = **官方公开校直接爬 + 不公开校靠案例反推 + 头部聚合文做种子**。

### 3.1 各英国大学公开程度（已逐校核实）

| 大学 | 公开形式 | 档位/均分（已核实） | 采集策略 |
|:--|:--|:--|:--|
| **爱丁堡** | ✅ 可下载 **PDF Priority List** | Band A 85% / B 80% / C 80-85% / D 80% | 直接爬 PDF（最优） |
| **UCL** | ✅ 官网内嵌完整名单 | list 内 85（2:1）/ list 外 90 | 爬 HTML 表 |
| **Sheffield** | ✅ 官网 + 在线 lookup 工具 | ARWU 四档 70/75/80/85% | 爬查询工具 |
| **Bristol** | ✅ 公开 accepted list（~266 校） | 名单内可申，分数线**不标**（78-87%） | 名单可爬，分数线靠案例补 |
| **Warwick** | ⚠️ 档位公开、名单细节散 | 四档 ~80/82/85/88 | 半自动 |
| **曼大/KCL/Glasgow/Leeds/南安** | ❌ **PG 名单不公开** | 曼大通用 80、金融 82-90；KCL 80/85 | **靠案例反推 + FOI**（核心壁垒） |
| **牛津/剑桥** | 官网原则性表述 | 牛津 85/88/90 三档 | 半自动录入 |

**关键洞察：壁垒不在已公开的校（谁都能爬），而在不公开名单+分数线的校（曼大/KCL/Glasgow/Leeds 的 PG 分档）——这部分只能靠案例反推，才是真正的隐性资产。**

官方 URL（已核实可用）：
- 爱丁堡：`ed.ac.uk/.../asia/china`（含 `priority_list_of_chinese_universities.pdf`）
- UCL：`ucl.ac.uk/prospective-students/international/china`
- Sheffield：`sheffield.ac.uk/international/entry-requirements/china`
- Bristol：`bristol.ac.uk/international/countries/china/accepted-universities-in-china/`
- 曼大（名单不公开）：`manchester.ac.uk/.../china-mainland/entry-requirements/`

### 3.2 第三方聚合源（已核实）
- **TestDaily 厚朴优学**（testdaily.cn/64451）：11 所 THE Top100 的"校名清单+分档均分"对照表，引官网为源。**2022 基线，已过期，只能当种子，全标 low 可信、待核。**
- 51offer/金吉列/高顿等中介自媒体：有逐年变动播报，可信度中（需交叉验证）。
- **WhatDoTheyKnow（FOI 平台）**：有人对曼大提交过"认可院校名单"信息公开请求——**拿曼大类不公开名单的合法正道**（页面 403，需浏览器/认证工具取附件）。
- **GitHub 无现成结构化数据集**；但有中国院校排名/标签数据，可做"中国院校主数据维表"。

### 3.3 从录取案例反推分数线（方法 + 坑）

利用已有 `undergrad_school + 均分 + 结果 + 目标校`（一亩三分地/寄托）反推不公开校的线：

**方法**
1. 给每个 `undergrad_school` 打标签：985/211/双一流/双非 + 软科排名段（英国校真实分档依据）。
2. 按 **(英国大学 × 专业大类 × 中国院校档)** 三维聚合（**必须分专业，否则商科高线污染全校**）。
3. **分数线 = 录取案例均分的低分位（P10-P25），而非均值**（门槛是最低能进的线）；更稳用 logistic / 等渗回归拟合 P(录取)=0.5 对应均分。

**样本量经验值（标注置信度，不给死值）**
- <5 例：仅提示，标"低可信/案例不足"
- 8-15 例且有录取也有拒绝：给**区间**估计（如"约 80-83"）
- ≥30 例：可给点估计 + 置信区间
- 无拒信的格子无法定线，只能给下界

**必须处理的坑**
- **幸存者偏差**：论坛多晒 offer 少晒拒 → 线被估高。缓解：加权拒信、用低分位、无拒信格只给下界并降可信度。
- **自我选择偏差**：双非很少敢申牛剑 → 样本偏尖子。标注"门槛可能被高估"。
- **专业混淆**：曼大金融 82-90 vs 通用 80 → 必须三维分。
- **均分口径/时间漂移**：归一化清洗、按年份分层、只用近 2-3 年。

### 3.4 冷启动三阶段
- **P0（1-2 周，覆盖 Top20 英国校）**：爬 4 所官方公开校（爱丁堡 PDF/UCL/Sheffield/Bristol）做骨架 + TestDaily 等聚合文手工录入另 ~16 校做种子（标 aggregator/低可信/待核）+ GitHub 中国院校维表。产出可查表，标注"参考线，非官方承诺"。
- **P1（1-2 月）**：接入案例反推曼大/KCL/Glasgow/Leeds 等不公开校实际线，校正 P0 种子值；对曼大类走 FOI 拿官方名单。每条带"案例支撑数+可信度"。
- **P2（持续保鲜）**：官方源每年 6-9 月定时重爬 diff 变动；案例源滚动增量、旧数据降权；聚合文/论坛关键词监控触发人工复核；超 `valid_until` 自动降级"待核"。

### 3.5 数据结构（3 张表）
```
cn_university(cn_uni_id PK, name_zh, name_en, aliases[],          -- 别名匹配案例乱写校名
  is_985, is_211, is_double_first_class, arwu_rank, qs_rank, ruanke_rank, tier_label)

uk_university(uk_uni_id PK, name_en, qs_rank,
  list_is_public BOOL, list_url, list_pdf_url, banding_scheme)    -- 如 "ARWU四档"/"Priority A-D"

entry_requirement(req_id PK, uk_uni_id FK,
  subject_group,                    -- 商科/工科/通用，一等公民，避免污染
  cn_tier, cn_uni_id FK NULL, degree_class_target,                -- 对标 2:1/2:2
  min_avg_score, score_low, score_high,                           -- 点估计 + 区间
  ielts_overall, ielts_sub,
  source_type ENUM('official_pdf','official_web','official_foi',
                   'aggregator','forum','agency','case_inferred'),
  source_url, source_year, confidence ENUM('high','medium','low'),
  sample_size, valid_until DATE, last_verified_at DATE, notes)
```

### 3.6 可信度与时效标注（防误导）
- **可信度**：official_* = high；aggregator = medium；forum/agency = low；case_inferred 按样本量升降。
- **时效**：官方 `valid_until = 申请季+1 年`；案例反推滚动 12 个月；过期自动降"待核"。
- **前端话术分层**：high→"官方公布门槛"；medium→"参考线，建议核对官网"；low/case→"基于历史案例估计，仅供参考，非录取承诺"。**永不把 case_inferred 包装成官方数字。**
- **冲突**：官方覆盖聚合、近年覆盖旧年，保留多源痕迹供人工裁决。

## 四、差异化定位总结（一句话）

> 指南者用**自有案例飞轮 + 人工顾问**做高端（985/211）重服务；我们用**透明可溯源的 list 数据 + LLM 对话式选校**做**双非/DIY 长尾的低价自助层**，把它锁在报告和顾问嘴里的"均分线/概率"彻底产品化、可验证化。
