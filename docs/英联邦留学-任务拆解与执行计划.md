## 五、已拍板的架构决策（ADR）

1. **等渗回归放独立 Python 脚本**（`scripts/fit_uk_entry_line.py`），不塞 dbt——dbt-postgres 不支持 Python model；dbt 出行级表→脚本拟合写回→dbt 当 source 引用，lineage 断点用 source freshness 测试补。
2. **LLM 批处理 = Haiku 4.5 + Batch API（5 折），低置信升级 Opus 4.8 仲裁；在线解释 = Sonnet 4.6**。全量批处理 <$50，成本非约束，加每日熔断防 bug 死循环。
3. **API 缓存 = 进程内 TTL，不上 Redis**——数据每日批更新、单实例、早期 QPS 极低。
4. **功能 1 解释 = 模板先行，LLM 润色作灰度开关**——零延迟零幻觉天然合规，P99 毫秒级。
5. **P0 不用 RAG，四功能全查表**——三维格子是精确结构化匹配，向量近似反而错配；把 GPA 塞进 embedding 是美研方案的错误用法，不平移。
