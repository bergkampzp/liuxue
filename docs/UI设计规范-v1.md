# 选校罗盘 UI 设计规范 v1（初步）

> 2026-06-12 经用户确认 | 适用于所有对外页面 | 来源：用户反馈 + 阿里云UI/UE规范 + js.design移动交互规范 + 知乎移动端交互指南(4大交互形式) + read.cv/B渐变视觉基准

## 1. 页面结构模式（核心）

**灰底白卡·模块化**：页面背景 `#f7f7f9`，内容装进白色模块卡（圆角 12px、内边距 18px、模块间距 ≥16px）。模块边界靠卡片而非留白。

每页固定四段式（按需删减但不打乱顺序）：
1. **主任务卡**（页面唯一视觉焦点，置顶）：模块标签(STEP X·紫色小字距1.5px) + 一行标题 + 一行副文 + 表单/内容 + 步骤条
2. **结果/内容区**：默认为**引导空态**（图标+将显示什么的说明+图例），绝不放可被误认为真实数据的伪内容；示例用 `<details>` 按需展开并明确标注"示例"
3. **信任带**：关键数字收敛为统计条（三格），佐证一行
4. **次级功能导航**：卡片入口，不与主任务抢焦点

## 2. 导航

- **移动端（≤640px）**：固定底部 Tab 栏，3-5 个高频入口，图标+文字，当前页紫色高亮，iPhone 安全区适配；顶部 nav 只留品牌+CTA
- **桌面端**：顶部 nav（品牌左、链接右、当前页加粗）
- 高频操作 ≤3 步可达；低频功能（方法论等）收入次级卡/Tab

## 3. 文字与色彩

- **三级文字色阶**：主文 `--ink #18181b` / 副文 `--gray #71717a` / 辅助 `--muted #a1a1aa`（对应阿里 #333/#666/#999 思想）
- **渐变只做点缀**（四处）：logo 色块 / 强调词(grad-text) / 主 CTA / 官方徽章。正文区禁用渐变
- 必填项标 `*`；下划线=可点链接
- 卡片内信息层级 ≤3 层（标题+徽章 / 副文 / 出处）

## 4. 反馈

- 按钮按下即时反馈 ≤100ms（disabled+文案变"查询中…"）
- 等待 >3s 必须有进度提示
- toast ~2.5s 自动消失，错误提示必须带解决方案（"未识别院校→请输入全称如'江苏大学'"）
- 危险/外发操作二次确认

## 5. 话术红线（沿用产品级规范，UI 强制位）

- 四态徽章必须紧跟数字：官方(渐变蓝)/参考线·待核(黄,行内必含"建议核对官网")/不在认可名单(红)/案例积累中(灰,绝不出数)
- 每个数字带可点"出处"；每页页脚一行免责（含"不构成录取承诺"）

## 6. 响应式

- 唯一断点 640px；输入组纵向堆叠、表格卡片化、卡组纵排
- 375px 无横向滚动为发布门禁；触达区 ≥44px

## 自查清单（每页发布前）

- [ ] 本页有且只有一个视觉焦点？
- [ ] 用户进来 3 秒内知道第一步做什么？
- [ ] 有无可被误认为真实数据的伪内容？
- [ ] 模块间距 ≥16px、卡片层级 ≤3 层？
- [ ] 375px 无横滚、Tab 栏在场、toast 不被遮挡？
