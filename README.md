# 国际学校 AI 智能体项目 (guoji-agent)

面向中国国际学校的 AI 赋能解决方案。首个落地模块：**教师多维度 AI 评价系统**。

## 项目背景

客户：北京某国际学校（IB/AP/A-Level 课程体系），已有 SaaS 系统、教学过程数据、课堂录播设备。

核心诉求：
1. **教师多维度评价**（⭕ 优先落地）
2. 学校智能大脑 + 家长一对一服务
3. 英联邦留学智能助手

## 当前阶段

Phase 1 — 教师多维度 AI 评价系统方案设计阶段。

## 技术方向

- AI 课堂分析（语音 ASR + Bloom 提问层次识别 + 视频行为分析）
- 增值评价模型（Student Growth Percentile）
- 大模型 + 传统 ML 混合架构（DeepSeek / Whisper / YOLOv8 等）
- 数据安全（边缘计算脱敏，原始视频不出校园）

## 协作方式

采用 SuperPower 多角色并行协作模式：@产品经理 @项目经理 @算法工程师 并行输出，整合为完整方案。
